Coinquiri

HTML CSS JavaScript Tailwind CSS Chart.js SheetJS Work in Progress

Coinquiri is a lightweight, local-first personal finance manager built as a static web app. It helps users track transactions, plan budgets and savings goals, and understand their cash flow without an account or backend.

Source code is not publicly available yet.

Key Features

  • Local transaction tracking with search, filters, and individual deletion
  • Budgets, savings goals, currency, language, and theme settings
  • Expense and 12-month cash-flow charts
  • Filtered monthly spreadsheet export and JSON backup/restore
  • Browser-local persistence with no account or server required
